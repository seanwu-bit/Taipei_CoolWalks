# 大安區行人適性路徑規劃與空間分析系統

姓名：胡舜宇
學號：R14521705

本專案旨在建構一個整合**「靜態建成環境」**與**「動態微氣候變數」**的行人適性路徑規劃與空間分析系統。透過定量評估行人在都市街區中所面臨的熱壓力、空氣污染與道路交通安全風險，設計出學術嚴謹的通行阻力成本函數 (Cost Function)，並利用路網最短路徑演算法 (Dijkstra) 求解最舒適、安全的步行路線。

---

## 🌐 核心概念 (Core Concepts)

在傳統導航系統中，通常僅考慮「最短距離」或「最短時間」。然而，對行人（特別是學童、年長者或對熱/空污敏感的群體）而言，暴露在極端高溫、強烈紫外線、嚴重空污（如 PM2.5）或缺乏實體人行道的路段會顯著增加生理負擔與安全威脅。

本專案的核心概念為：**「將環境舒適度與交通安全性轉化為路網通行阻力」**。藉由空間分析方法，我們將多源環境感測指標與建成環境特徵融合，針對不同的行人情境需求，量身打造適性導航路線。

## 🛠️ 空間分析方法與數學公式 (Spatial Analysis Methods)

本系統的空間分析方法可拆解為指標預處理、指標正規化、環境熱阻力建模、安全與空污懲罰、綜合阻力成本計算，以及最佳路徑環境特徵擷取與 Gemini 醫療保健出行建議：

### 1. 指標預處理與截斷機制 (Clipping)
為避免極端異常值（如資料鍵入錯誤導致負值或異常大數值）破壞成本函數的數學邏輯，對所有輸入指標實施上下限截斷：
* 綠意遮陰率：$S_{green} = \min(\max(shading\_index, 0.0), 1.0)$
* 房屋建物遮陰率：$S_{bldg} = \min(\max(dynamic\_shadow\_ratio, 0.0), 1.0)$
* 行人安全係數：$Safety = \min(\max(safety\_score, 0.0), 1.0)$

### 2. 微氣候與空污指標正規化 (Normalization)
將不同物理單位的環境指標，等比縮放至 $[0.0, 1.0]$ 的無因次懲罰值：
* **乾濕球溫度 (WBGT)**：以舒適溫度 $20^\circ\text{C}$ 為起點，極度高溫危險值 $33^\circ\text{C}$ 為上限。
  $$T_{norm} = \min\left(\max\left(\frac{dynamic\_wbgt\_c - 20}{33 - 20}, 0.0\right), 1.0\right)$$
* **紫外線指數 (UVI)**：以 WHO 國際防護標準之極限危險值 $11.0$ 為上限。
  $$UV_{norm} = \min\left(\max\left(\frac{dynamic\_uv\_index}{11.0}, 0.0\right), 1.0\right)$$
* **細懸浮微粒 (PM2.5)**：基於大氣空間 Kriging 克利金插值結果，以普通標準上限 $50.0\,\mu\text{g/m}^3$ 為懲罰上限。
  $$PM_{norm} = \min\left(\max\left(\frac{dynamic\_pm25\_kriging}{50.0}, 0.0\right), 1.0\right)$$

### 3. 環境熱壓力與遮陰緩解效應 ($P_{env}$)
結合綠蔭（綠意遮陰率 $S_{green}$）與建物（房屋遮陰率 $S_{bldg}$）的遮陰效果。為避免空間重複計算，採用**機率聯集**計算綜合遮陰率 $S_{total}$：
$$S_{total} = S_{green} + S_{bldg} - (S_{green} \times S_{bldg})$$

環境熱壓力懲罰值 $P_{env}$ 由溫度與紫外線加權組成，並直接受到遮陰率的消減（遮陰可阻擋熱壓力）：
$$P_{env} = (\alpha \cdot T_{norm} + \beta \cdot UV_{norm}) \times (1.0 - S_{total})$$
* **參數設定**：$\alpha = 0.8$（熱壓力對人體急性熱危害影響大，權重高），$\beta = 0.2$（紫外線防護屬次要權重）。

### 4. 安全與空污懲罰阻力
* 安全懲罰阻力（安全分數越高，阻力越低）：$P_{safe} = 1.0 - Safety$
* 空污懲罰阻力：$P_{air} = PM_{norm}$

### 5. 總體通行成本函數 ($Cost$) 與單位距離成本 ($Unit\_Cost$)
各路段（Edge）的通行阻力總成本與長度成正比，並受到環境、安全及空污的綜合權重懲罰：
$$Cost = length \times (1.0 + W_{env} \cdot P_{env} + W_{safe} \cdot P_{safe} + W_{air} \cdot P_{air})$$
$$Unit\_Cost = \frac{Cost}{length} = 1.0 + W_{env} \cdot P_{env} + W_{safe} \cdot P_{safe} + W_{air} \cdot P_{air}$$

#### 情境權重矩陣：
本專案支援三種典型行人情境模式之權重配置：
| 情境模式 | 環境熱權重 ($W_{env}$) | 安全權重 ($W_{safe}$) | 空污權重 ($W_{air}$) | 說明 |
| :--- | :---: | :---: | :---: | :--- |
| **均衡通勤模式 (Balanced)** | `1.0` | `1.0` | `0.5` | 兼顧通行舒適度、安全與空污，為導航預設模式。 |
| **極端避暑模式 (Heat-Averse)** | `2.0` | `0.5` | `0.2` | 強調避開直射日曬與高溫，最大化選擇遮陰路段。 |
| **弱勢行人模式 (Safety-First)** | `0.5` | `2.0` | `0.5` | 極力保障交通安全，避開無實體人行道、事故率高的路段。 |

### 6. 路徑環境暴露特徵擷取與 Gemini 醫療保健出行建議
在最佳路徑求解完成後，為了量化行人在路徑上的暴露，以路段長度為權重，計算整條路徑的環境指標加權平均值：
$$Avg\_Value = \frac{\sum_{i=1}^{k-1} (Value_i \times length_i)}{\sum_{i=1}^{k-1} length_i}$$
擷取指標包含：平均 WBGT 溫度、平均綠意遮陰率、平均建物遮陰率、平均 PM2.5 濃度、平均紫外線指數以及平均道路安全得分。

將這些加權平均暴露值發送至 Gemini API (使用最新的 `gemini-2.5-flash` 模型)，並取得客製化且實用的個人化戶外健康與防護出行建議，最終整合於地圖氣泡視窗中。

## 🗂️ Pipeline 架構設計

本系統程式設計高度模組化，分成四個主要執行模組（皆置於 `scripts/`，並在 `outputs/` 中產出中間與最終成果檔案）：

```
[大安區原始路網] Daan_Shaded_Network.graphml
       │
       ▼
M1_data_validator.py   ───> 產出 M1_validated_network.graphml  (指標完整性檢查與缺失值補植)
       │
       ▼
M2_cost_calculator.py  ───> 產出 M2_costed_network.graphml     (各情境 Cost & Unit_Cost 計算)
       │
       ▼
M3_path_router.py      ───> 產出 M3_optimal_paths.json          (路徑求解與串接 Gemini API 建議生成)
       │
       ▼
M4_map_visualizer.py   ───> 產出 M4_routing_result.html         (全區阻力底圖與互動式地圖視覺化)
```

* **Gemini API 快取與 Fallback 機制**：系統會比對先前生成的路徑 JSON，若路線未改變則直接沿用快取以節約 API 額度；若無網路或金鑰失效，會自動使用規則引擎生成備用防護建議，保證 Pipeline 正常執行不中斷。
* **效能優化技術 (Multi-Polyline)**：將單位阻力成本分入 20 個色彩分桶 (Color Bins)，將同色路段合併為單一 Multi-Polyline 渲染，將 HTML 壓縮至 **1.97MB**，保證載入與滑動體驗極致流暢。
* **絕對分級機制**：色彩圖例（Colormap）範圍完全鎖死在 `vmin = 1.0` (極度舒適, 綠色) 至 `vmax = 3.0` (極高懲罰, 紅色)，客觀呈現全區環境阻力的真實分布。

## 🚀 快速開始 (How to Run)

### 1. 安裝與啟用 conda 空間分析環境
確保系統中已安裝 Anaconda/Miniconda，並根據專案根目錄的 `environment.yml` 建立並啟用環境：
```bash
conda env create -f environment.yml
conda activate geospatial
```

### 2. 執行全套分析 Pipeline
在啟用 `geospatial` 後，建議在 Powershell 中以如下指令注入 PATH 並啟動 Pipeline 控制腳本：

```powershell
$env:PATH = "C:\Users\ASUS\anaconda3\envs\geospatial\Library\bin;" + $env:PATH
python -u scripts/run_pipeline.py
```

執行完畢後，即可於 `outputs/` 資料夾下取得各階段產出的 `.graphml` 圖資、路徑 JSON、以及 `M4_routing_result.html` 地圖網頁！
